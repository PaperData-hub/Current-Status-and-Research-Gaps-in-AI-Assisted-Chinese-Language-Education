# 독립 재판정 지침 (κ 표본 200편, 2026-10-01)

각 논문의 **제목·주제어·초록·학술지·연도만** 보고, 아래 기준에 따라 독립적으로 판정·코딩한다.
이 지침과 배정된 입력 파일 외의 파일(특히 `data/rejudge/`, `data/kappa/κ표본_정답키*`, `data/*.xlsx`, `analysis/`)은 열지 않는다.
다른 판정 결과를 참고하지 않는 것이 이 작업의 목적이다.

## 1. 포함 기준 — 두 조건을 모두 충족하면 포함(include = "Y")

- **(가) AI 조건**: AI 기술을 연구의 실질적 대상 또는 도구로 다룬다. 생성형 AI·ChatGPT·대규모 언어모델, 챗봇, 기계번역기(파파고·구글번역·DeepL),
  음성인식·음성합성, 자동채점·자동피드백, BERT 등 언어모델·자연어처리, AI 스피커, 지능형 튜터링 등. 단순 언급이나 배경 서술만으로는 부족하다.
  메타버스·VR·앱·온라인 수업처럼 AI가 아닌 에듀테크는 AI가 아니다.
- **(나) 언어교육 조건**: 영어·한국어·중국어 가운데 **한 언어**의 교수·학습·평가·교재·학습자를 다룬다. 학습자가 모어 화자인지 외국어 학습자인지는 가리지 않는다.

## 2. 경계 범주의 처리

- **국어 교과**: AI를 국어과의 쓰기·문법·읽기 지도나 평가에 적용·분석·개발한 연구는 포함. AI 시대 국어 교과의 대응 방향·쟁점만 논의한 담론·시론은 제외(국어교과담론).
- **대학 교양**: 대학 교양 교과의 국어 글쓰기·읽기·토론 교육과 교양교육 일반 연구는 제외(교양교육). 외국어 교과로 개설된 교양 영어·중국어 수업 연구는 해당 외국어교육으로 포함.
  AI 자동채점·자동피드백·화법 평가 도구를 개발하거나 검증한 연구는 교양 맥락이어도 포함.
- **AI 디지털교과서**: AI 디지털교과서 자체의 정책·수업 모형·교사·학생 인식·교과서 분석 연구는 제외(AI디지털교과서). AI 디지털교과서가 맥락일 뿐 특정 AI 도구의 언어 교수·학습을 검증한 연구는 포함.
- **통번역 교육**: AI를 통번역 수업·번역 교육에 적용한 연구는 대상 언어쌍에 따라 영어·한국어·중국어 가운데 하나로 분류해 포함. 학습자·수업 맥락이 없는 번역 품질·성능·산업 연구는 제외(번역품질).
- **문법·자연어처리**: 교육적 적용이나 시사점이 초록에 실질적으로 있으면 포함, 순수 언어학·자연어처리 성능 연구는 제외(교육맥락없음).
- **복수언어·언어 미명시**: 여러 언어를 함께 다루거나 비교한 연구는 제외(복수언어). 대상 언어를 특정할 수 없는 연구는 제외(언어비특정). 한 언어만 다룬 연구는 그 언어로 분류.

## 3. 제외 사유 코드 (include = "N"일 때 하나만)

| 언어비특정 | 언어를 특정하지 않는 일반 AI 교육 연구(타 교과, 교육 일반), 언어 교수·학습을 다루지 않는 연구(유학생의 학업 전반 AI 활용 등) |

## 4. 포함 논문의 코딩 (include = "Y"일 때)

- **group**: 영어 / 한국어 / 중국어. "외국어교육" 일반이라도 자료와 사례가 특정 언어이면 그 언어.
- **learner**: 한국어군만. L1(한국어 모어 화자 대상 국어·글쓰기·독서 교육) / L2(외국인·유학생·다문화 학습자 대상 한국어 교육) / 미명시. 영어·중국어군은 "".
- **func**(주된 언어기능, 하나): 쓰기 / 말하기 / 평가·채점 / 읽기 / 리터러시·역량 / 번역 / 문법 / 문학·문화 / 발음 / 어휘 / 듣기 / 기능비특정.
  여러 기능이면 제목·초록에서 비중이 가장 큰 기능. 평가·채점은 자동채점·문항 생성·평가 도구가 주된 대상인 경우(쓰기 평가라도 채점 자체가 초점이면 평가·채점,
  쓰기 지도가 초점이면 쓰기). 리터러시·역량은 AI·프롬프트·디지털 리터러시 자체를 다룬 경우. 기능비특정은 교사 인식·역량, 학습자 수용·태도, 연구 동향, 일반 활용 제언,
  기능 비특정 도구 개발처럼 특정 기능으로 환원되지 않는 연구.
- **meth**(주된 연구방법, 하나): 실험연구(집단 간·시점 간 변화 비교, 사전·사후, 준실험 포함) / 조사연구(설문으로 인식·태도·요구·수용 의도·현황 조사) /
  질적·사례(수업 실행·학습 경험 기술, 사례연구, 면담·관찰·담화 분석) / 개발연구(도구·시스템·수업 모형·교재·프로그램·프롬프트 설계·개발) /
  성능평가(AI 산출물의 정확성·품질 검토) / 문헌·리뷰(문헌 검토, 체계적 문헌분석, 동향·메타분석, 이론적 고찰, 시론·담론) /
  코퍼스분석(학습자 산출물·텍스트·키워드의 계량 분석) / 기타·혼합. 주된 연구 목적에 답하는 설계 하나. 개발 후 만족도 설문을 붙였으면 개발연구,
  개발 후 통제집단 효과 검증이 핵심이면 실험연구.
- **tool**(핵심 도구, 하나): ChatGPT / 생성형AI일반(Gemini·Claude·뤼튼 등 또는 생성형 AI 총칭) / 중국어LLM(어니봇·딥시크 등) / 챗봇(비생성형·규칙 기반·AI 스피커 등) /
  기계번역 / 음성인식·TTS / BERT·NLP(사전학습모델·자연어처리·머신러닝·자동채점 엔진) / 기타.

## 5. 출력

배정된 입력 파일의 모든 논문에 대해 아래 객체 배열을 지정된 출력 경로에 UTF-8 JSON으로 저장한다. 입력 순서와 건수를 지키고 누락하지 않는다.

```json
{"no": 1, "id": "ART00...", "include": "Y", "reason": "", "group": "중국어", "learner": "", "func": "말하기", "meth": "개발연구",
 "tool": "ChatGPT", "confidence": "high", "note": "판정 근거 한 줄(40자 이내)"}
```

include = "N"이면 reason 필수, group·learner·func·meth·tool은 "". confidence는 high / mid / low(초록만으로 판정이 어려움).
