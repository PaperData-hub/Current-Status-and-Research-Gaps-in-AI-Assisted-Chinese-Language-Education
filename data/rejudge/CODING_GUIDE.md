# 코퍼스 재판정·코딩 지침 (2026-09-29, 저자 결정 반영)

논문 「AI 활용 중국어교육 연구의 현황과 공백: 영어·한국어교육과의 계량서지·네트워크 비교」(투고번호 생략)의
분석 코퍼스를 1차 수집본 1,644편에서 다시 확정한다. 각 논문의 **제목·주제어·초록**을 읽고 아래 항목을 판정한다.
규칙 판정값(prev_*)은 참고만 하고, 초록을 근거로 독립적으로 판정한다.

## 1. 포함 기준 (두 조건을 모두 충족해야 포함)

**단 하나의 원칙: [AI + 언어교육]에 해당하면 포함, 아니면 제외.**

- (가) **AI 조건**: 인공지능 기술(생성형 AI·ChatGPT·LLM, 챗봇, 기계번역기(파파고·구글번역·DeepL), 음성인식·TTS,
  자동채점·자동피드백, BERT 등 언어모델·NLP, AI 스피커, 지능형 튜터링 등)을 연구의 **실질적 대상 또는 도구**로 다룬다.
  단순 언급이나 배경 서술만으로는 부족하다. 메타버스·VR·앱·온라인수업 등 AI가 아닌 에듀테크는 AI가 아니다.
- (나) **언어교육 조건**: 영어·한국어·중국어 중 한 언어의 **교수·학습·평가·교재·학습자**를 다룬다.
  - 학습자가 모어(L1) 화자인지 외국어(L2) 학습자인지는 가리지 않는다(논문 각주 3). 한국 학생의 국어 작문·대학 글쓰기 교육,
    외국인의 한국어 학습 모두 포함 대상이다.
  - 통번역 수업·번역 교육 논문도 AI를 언어교육(번역 수업·학습자 번역 훈련·포스트에디팅 교육 등)에 적용·분석했으면 **포함**한다.
    학습자·수업·교육 맥락이 없는 번역 품질·번역 오류·번역 산업 연구는 제외한다.
  - 문법·NLP 계열 논문(예: BERT로 중국어 문법 예측)도 교육적 적용·시사점이 초록에 실질적으로 있으면 포함, 순수 언어학·NLP 성능 연구면 제외.

| 언어비특정 | 언어를 특정하지 않는 일반 AI 교육 연구(수학·사회 등 타 교과, 교육 일반, 유학생의 AI 수용 등 언어교육 아닌 것) |

## 2. 국어 교과 담론형 제외 (저자 결정, 2026-09-29)

한국어군 L1(모어 화자 대상 국어교육·글쓰기 교육)은 유지한다. 다만 **국어 교과 담론형**은 제외한다.
- **제외(국어교과담론)**: 국어 교과(국어교육학연구·청람어문교육·국어교육 등 국어교육 학회 계열 포함)에서 AI 시대 교과의 대응 방향,
  교육과정·정책 방향, 국어교육의 위상·쟁점 등을 **논의만** 하는 담론·시론·방향론. AI 도구를 언어 수업·평가·학습자에 실제로
  적용·분석·개발하지 않은 것. 예: "챗지피티의 등장과 국어교육의 대응", "AI 시대 국어교육의 방향".
- **유지**: 국어 교과라도 AI를 쓰기 피드백·문법 문항·읽기 지도 등에 실제로 적용·분석·개발·성능평가한 실증 논문,
  그리고 체계적 문헌분석·계량서지처럼 데이터에 근거한 동향 분석.
- 영어군·중국어군·L2 한국어군의 담론·시론(예: "생성형 AI 시대 영어교육의 방향")은 포함하되 paper_type을 "담론"으로 표시한다.

## 3. 언어군 (group) — 포함 시 필수

영어 / 한국어 / 중국어 중 하나. 복수 언어를 다루면 초록에서 비중이 가장 큰 언어. 비중이 같으면 저자 소속 분야·학술지 분야로 판단하고 boundary="Y".
- "외국어 교육" 일반이되 데이터·사례가 특정 언어(예: 영어 수업)이면 그 언어. 정말 언어를 특정할 수 없으면 제외(언어비특정).
- 한국어군의 learner: **L1**(한국 모어 화자 대상 국어·글쓰기·독서 교육), **L2**(외국인·유학생·다문화·KFL/KSL·TOPIK),
  **미명시**(초록에서 판단 불가). 영어·중국어군은 learner를 ""로 둔다.

## 4. 언어기능(주) (func) — 포함 시 필수, 하나만

쓰기 / 말하기 / 평가·채점 / 읽기 / 리터러시·역량 / 번역 / 문법 / 문학·문화 / 발음 / 어휘 / 듣기 / 기능비특정
- AI가 적용된 **교수·학습 과제**. 복수 기능이면 제목·초록에서 가장 비중이 큰 기능 하나.
- 평가·채점: 자동채점·문항 생성·평가 도구가 주 대상(쓰기 평가라도 채점 자체가 초점이면 평가·채점, 쓰기 지도가 초점이면 쓰기).
- 리터러시·역량: AI 리터러시·프롬프트 리터러시·디지털 역량 자체를 다룸.
- 문학·문화: 문학 작품·문화 교육에 AI 적용.
- 기능비특정: 특정 기능으로 환원되지 않는 연구(교사 인식·역량, 학습자 수용·태도, 연구동향, 일반 활용 제언, 기능 비특정 도구 개발).
  이때 focus를 반드시 채운다: 교사·교육주체 / 학습자 인식·수용·정의적 / 연구동향·메타분석 / 일반 논의·활용 제언 / 도구·자원 개발

## 5. 연구방법(주) (meth) — 포함 시 필수, 하나만

| 범주 | 정의 |
|---|---|
| 실험연구 | 집단 간 또는 시점 간 변화를 비교(통제·비교집단, 사전·사후검사, 준실험, 단일집단 사전·사후 포함) |
| 조사연구 | 설문·인식·태도·요구·수용의도 조사(TAM·UTAUT 등), 현황 조사 |
| 질적·사례 | 수업 실행·학습 경험 과정 기술, 사례연구, 면담·관찰·담화분석 중심 |
| 개발연구 | 도구·시스템·수업 모형·교재·프로그램·프롬프트 설계와 개발(적용 사례 소개 포함) |
| 성능평가 | AI 산출물·응답의 정확성·품질을 검토(ChatGPT 답안 평가, 번역기 성능 비교, 채점 일치도 등) |
| 문헌·리뷰 | 문헌 검토, 체계적 문헌분석, 동향·메타분석, 이론적 고찰, 시론·담론·제언 |
| 코퍼스분석 | 학습자 산출물·텍스트·키워드 데이터의 계량 분석(코퍼스언어학·텍스트마이닝·토픽모델링 등) |
| 기타·혼합 | 위 범주 하나로 정하기 어려운 혼합 설계 |

주된 연구 목적에 답하는 설계 하나만 부여한다. 개발 후 만족도 설문을 붙였으면 개발연구, 개발 후 통제집단 효과검증이 핵심이면 실험연구.

## 6. 핵심도구 (tool) — 포함 시 필수, 하나만

ChatGPT / 생성형AI일반(Gemini·Claude·뤼튼 등 또는 생성형 AI 총칭) / 중국어LLM(어니봇·딥시크·文心一言 등) / 챗봇(비생성형·규칙기반·AI 스피커·펭톡 등) /
기계번역(파파고·구글번역·DeepL·NMT) / 음성인식·TTS / BERT·NLP(사전학습모델·NLP·머신러닝·자동채점 엔진) / 기타

## 7. 보조 항목

- ai_role: 콘텐츠생성 / 상호작용 / 피드백·평가 / 교수자료설계지원 / 기타 / "" (초록에 명시된 경우만)
- paper_type: 실증(데이터 수집·분석) / 개발 / 문헌리뷰(체계적·계량) / 담론(시론·방향론·제언) / 성능검토
- confidence: high / mid / low (low = 초록만으로 판정이 어려움)
- boundary: "Y"이면 저자 검수 대상(포함·제외 경계, 언어군 경계, 국어교과담론 여부 애매, 기능·방법 경계). 그 외 "N".
- note: 판정 근거 한 줄(40자 이내). 특히 prev_include와 판정이 다르면 이유를 쓴다.

## 8. 출력 형식

배치 파일의 모든 레코드에 대해 아래 JSON 객체 배열을 `data/rejudge/out/<배치명>.json`에 UTF-8로 저장한다. 레코드 누락 금지, 순서 유지.

```json
{"id":"ART00...", "include":"Y", "reason":"", "group":"중국어", "learner":"", "func":"말하기", "meth":"개발연구",
 "tool":"ChatGPT", "focus":"", "ai_role":"상호작용", "paper_type":"개발", "confidence":"high", "boundary":"N", "note":"..."}
```
include="N"이면 reason 필수, group은 판단되면 기입(아니면 ""), func/meth/tool/focus/ai_role은 "".
